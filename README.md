# 🚚 Data-Driven Supply Chain Optimization & Delay Prediction

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** and **Supply Chain Analytics** to identify the key factors affecting delivery performance and operational efficiency. The analysis aims to uncover hidden patterns in supply chain data, understand delivery delays, and prepare the dataset for predictive modeling.

The project can help businesses optimize logistics, reduce delivery delays, improve customer satisfaction, and make data-driven operational decisions.

---

## 🎯 Objectives

- Analyze supply chain operations
- Identify factors causing delivery delays
- Explore customer and product trends
- Clean and preprocess the dataset
- Perform feature engineering
- Generate actionable business insights
- Prepare the data for machine learning models

The dataset contains information related to supply chain operations, including features such as:
